What is in this folder:
- index.html
- styles.css
- manifesto.html
- notes-margins-thinking.html
- the-shape-of-a-sentence-after-midnight.html
- the shape of a sentence after midnight.html (compatibility copy)
- contact.html

How to test locally:
1. Open index.html in a web browser.
2. Click the links to make sure each page loads.

How to upload to a hosting site:
1. Upload all files in this folder together.
2. Keep index.html in the top level.
3. Do not rename styles.css.
4. If your host asks for a publish directory, use this folder.

Notes:
- This is a static site. The contact form is a styled placeholder until connected to a form service.
- The compatibility copy with spaces is included in case any old link still points to that filename.
